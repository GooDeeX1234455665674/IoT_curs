# IoT-система учёта лабораторного оборудования 
Перелыгин О.А. Зиневич Р.С. ЭВМб-23-1

О ПРОЕКТЕ

Проект представляет собой IoT-систему автоматизированной выдачи и возврата оборудования для выполнения лабораторных работ.

Лабораторное оборудование хранится в специальных ящиках. Доступ к ним осуществляется с помощью NFC-меток. Система идентифицирует пользователя, предоставляет доступ к оборудованию и автоматически фиксирует информацию о его использовании.

В рамках курсового проекта разрабатывается прототип системы, имитирующий работу механизма открытия и закрытия ящика.

ЦЕЛЬ ПРОЕКТА

Разработать прототип IoT-системы для автоматизации хранения, выдачи и возврата лабораторного оборудования.

ПРИНЦИП РАБОТЫ

1. Студент прикладывает NFC-метку к считывателю.
2. Система идентифицирует пользователя.
3. При успешной идентификации активируется механизм открытия ящика.
4. Студент получает комплект оборудования для выполнения лабораторной работы.
5. В базе данных фиксируются ФИО студента, дата и время получения оборудования.
6. После выполнения работы студент возвращает оборудование.
7. Система проверяет наличие возвращённого оборудования с помощью датчиков.
8. После успешной проверки активируется механизм закрытия ящика.
9. В базе данных фиксируется время возврата и рассчитывается продолжительность использования оборудования.

ОСНОВНЫЕ ВОЗМОЖНОСТИ 

* идентификация студентов по NFC-меткам;
* управление механизмом открытия и закрытия;
* контроль наличия оборудования;
* фиксация выдачи и возврата оборудования;
* сохранение ФИО пользователя;
* сохранение даты и времени выдачи;
* определение времени возврата;
* расчёт продолжительности использования;
* хранение истории операций в базе данных.

АППАРАТНАЯ ЧАСТЬ

В прототипе планируется использовать:

* микроконтроллер;
* NFC/RFID-считыватель;
* NFC-метки;
* сервопривод или электродвигатель для имитации открытия и закрытия ящика;
* датчики для контроля наличия оборудования;
* макетную плату;
* соединительные провода;
* дополнительные электронные компоненты.

ПРОГРАММНАЯ ЧАСТЬ

Программная часть системы должна обеспечивать:

* взаимодействие микроконтроллера с NFC-считывателем;
* управление механизмом открытия и закрытия;
* получение данных с датчиков;
* передачу информации в базу данных;
* регистрацию выдачи и возврата оборудования;
* хранение истории использования оборудования.

РЕАЛИЗАЦИЯ ПРОЕКТА

В рамках курсового проекта физический ящик для хранения оборудования не создаётся.

Работа системы моделируется на лабораторном стенде. Электропривод имитирует открытие и закрытие ящика, а подключённые датчики используются для определения факта возврата оборудования.

Такой прототип позволяет продемонстрировать основной принцип работы системы без создания полноразмерной конструкции.
